验证日期：2026-11-07。验证对象：Windows x64、.NET Framework 4.8 / WPF 的独立预览。此次公开版本整理不启动或操作真实 Codex 客户端。

| 检查 | 内容 |

| WPF 编译 | 使用 Windows 自带 .NET Framework 编译器，不依赖私人图片或视频 |
| `--self-test` | 605 个几何采样、12 个固定窗口位置用例；不打开窗口 |
| `GeometryTests.exe` | 22 项几何/配置断言 |

| GIF 测试 | 程序创建的两帧红/蓝测试 GIF；检查解码、帧间隔、循环与像素变化，不使用参考人物 GIF |

| 公开文件检查 | 排除私人素材、生成记录、构建输出、实际配置，并检查常见凭据标记与个人绝对路径 |

上述检查已在本地通过。公开源码副本不包含私人人物图、参考录屏或上游视频，并单独用于验证构建、测试和打包。自动检查仅覆盖列出的规则，不等同于完整安全审计。

## 人工验收边界

本次整理未重新进行完整播放、键盘交互或多显示器人工验收，也未验证 macOS。分镜导出及像素断言不能替代这些检查。

仍需人工确认：

- 实时播放的节奏、配色、流畅度，以及 Space / R / 1–5 / Esc 操作。
- 不同 DPI、分辨率和窗口尺寸下的布局与清晰度。
- 自行替换人物素材后的构图、边缘融合；静态图只参与画面显现，不是完整角色动画。
- 自行添加音频后的本机解码、音量和时间轴。公开版本无音轨且默认静音。

真实客户端启动、窗口就绪等待、DWM 交接、快捷方式替换、磁盘扫描和官方客户端文件修改不在当前执行与验证范围内。本阶段不运行 `tests/EntrypointTests.ps1`，不声明固定帧率或全显示器兼容性。
