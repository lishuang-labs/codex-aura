## 可丢弃窗口集成测试

`scripts/test-launch-windows.ps1` 会显示程序创建的空白测试窗口。本次 7 个场景的 71 项断言通过；追加开场屏幕像素检查后，定向复测 `-Cases normal,fallback` 的 26 项断言通过。测试程序与启动器均启用 Per-Monitor V2 DPI：

- 正常 DWM 交接、前台焦点确认，目标窗口位置和尺寸不变。
- 关闭 DWM 后通过窗口淡出完成交接。
- 测试窗口暂时不响应，人物画面等待，恢复稳定后继续交接。
- 等待超时按时退出并返回 2。
- 交接中测试窗口消失，清理缩略图并在等待预算耗尽后退出。
- 正常、最大化、播放中移动和缩放时，动画窗口与目标完整可见边界的误差不超过 1 个物理像素。
- 动画窗口没有任务栏和 Alt-Tab 独立条目；交接在关闭覆盖层前请求目标激活。
- 开场顺序为隐藏原生窗口、完成首帧绘制、显示匹配真实窗口的动画；播放中确认窗口已解除隐藏。
- 对自建空白测试窗口上的动画捕获开场第一秒 PNG，像素检查及人工查看均确认 Codex 标识已出现，右上角没有跳过按钮；未捕获真实客户端内容。

测试只清理自己创建的临时进程，不查杀真实客户端。运行测试期间不要同时用其他自动化操作桌面，以免干扰前台焦点断言。

`tests/EntrypointTests.ps1` 的 37 项隔离断言通过：显式路径安装不遍历目录，未选中的官方入口和无关同名入口不变，原文件逐字节恢复，用户后续修改保留，损坏备份拒绝恢复。测试不修改实际用户入口。

## 本机真实桌面检查

- 在正常用户桌面复用当前已打开的 Codex；完整动画结束后 DWM 连接成功，返回码 0，日志确认前台窗口已交接。
- 使用独立配置副本把时长暂设为 45 秒，通过 Computer Use 查看环形界面并按 Esc，确认覆盖窗口关闭、返回码 0，焦点回到真实 Codex。实际交付配置仍为 16 秒。
- 隔离执行环境中无法发现正常桌面的客户端时，观察到等待超时且返回 2。真实桌面检查改在正常用户会话执行；没有把隔离环境中的启动请求当作成功交接。
- 显式安装桌面和用户开始菜单的两个 `Codex.lnk`，使用本机客户端图标和 `--launch`。报告确认创建 2 项、检查 2 个链接、扫描 0 个目录、错误 0 项；固定后两个文件的安装哈希仍匹配。
- 使用 Computer Use 固定新 Codex 快捷方式到开始菜单；右键菜单变为“从开始菜单取消固定”，确认已固定。原注册应用、旧固定项和任务栏固定项保持原样。
- 修正关闭覆盖层前的激活顺序后，再从已安装的开始菜单 `Codex.lnk` 运行完整 16 秒动画：复用真实窗口、匹配其可见边界、DWM 连接成功，最终日志 `foreground=True`。没有重新启动或关闭当前客户端。
- 修复开头黑框后，从桌面 `Codex.lnk` 复测完整 16 秒播放：日志确认先隐藏窗口，再完成首帧、显现动画、交接真实窗口；退出码 0、前台焦点交接成功。真实冷启动仍待用户验收。
