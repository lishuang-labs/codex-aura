# 用户资产

公开仓库仅包含 `character-placeholder.png` 和本说明。占位剪影由 `PreviewScene.Placeholder()` 绘制，可在构建后通过 `scripts/create-placeholder.ps1` 重新生成。

自定义 PNG/JPG/GIF 可放在本目录供本地构建使用，也可直接放在运行目录的 `assets/`。实际人物路径由 exe 同目录的 `launcher.json` 指定，已有本地配置会保留。

其他素材及生成提示词均默认忽略，不进入公开源码或发布包。使用者应自行确认角色、图片、音频与图标的使用和再分发权限。代码 MIT 许可不改变素材的许可。
